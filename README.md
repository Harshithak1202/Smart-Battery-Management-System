# Smart Battery Management System for Electric Vehicles with AI-Based Battery Health Prediction

## Project Description
This project develops a Smart Battery Management System (BMS) for Electric Vehicles using Artificial Intelligence. The system monitors battery voltage, current, and temperature and predicts the battery's State of Health (SOH) using machine learning techniques.

## Objectives
- Monitor battery voltage
- Monitor battery current
- Monitor battery temperature
- Predict battery health using AI
- Improve battery safety and performance

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- GitHub
